# Insurance Income Statement Projection & Scenario Analysis

## Overview

This project is an Excel-based insurance financial projection model designed to forecast key components of an insurer's income statement.

The model projects premiums, claims, expenses, investment income, insurance liabilities, and net income while allowing alternative assumptions and interest-rate scenarios to be evaluated.

## Project Objectives

The project was developed to:

- Project key insurance income statement components
- Forecast premiums and claims over multiple periods
- Incorporate insurance expenses and investment income
- Account for changes in insurance liabilities
- Estimate projected net income
- Evaluate financial performance under alternative assumptions
- Assess the impact of different interest-rate scenarios

## Model Components

The Excel model incorporates key insurance financial variables, including:

- Premiums
- Claims
- Expenses
- Investment income
- Insurance liabilities
- Net income

These components are integrated to provide a structured projection of the insurer's financial performance.

## Scenario Analysis

The model allows key assumptions to be adjusted to examine how changes in underlying variables affect projected financial results.

Alternative interest-rate scenarios are also incorporated to assess their impact on investment income and overall financial performance.

This provides a framework for comparing outcomes under different financial assumptions rather than relying on a single projection.
